# Merlin – AI Personal Assistant Bot

مرلین یک پروژه آینده‌محور و چندزبانه برای ساخت یک ربات دستیار شخصی هوشمند است که می‌تواند مانند یک دوست دیجیتال به شما کمک کند، جواب سؤال‌ها را بدهد، یادآور بگذارد، و امور روزمره را ساده‌تر کند.

---

## 🎯 اهداف پروژه
- ساخت یک ربات ماژولار و قابل گسترش
- استفاده از یادگیری ماشین و پردازش زبان طبیعی
- «دستیار شخصی» که بتواند با چند زبان (فارسی، کردی، آلمانی، انگلیسی و …) ارتباط بگیرد
- خودآموز و شخصی‌ساز شده بر اساس سلیقه کاربر
- تاکید بر امنیت داده و حریم خصوصی

---

## 🛣️ نقشه راه (Roadmap)
اطلاعات دقیق‌تر در فایل [roadmap.md](./roadmap.md) موجود است.

1. تحقیقات و انتخاب فناوری مناسب (پایتون، کتابخانه‌ها و ابزارها)
2. طراحی هسته پروژه و الگوریتم‌های پایه
3. توسعه نمونه اولیه برای مکالمه متنی ساده
4. افزودن ماژول‌های NLP و یادگیری ماشینی
5. اتصال به APIهای خارجی (تقویم، ایمیل و …)
6. تست و جمع‌آوری بازخورد کاربران
7. ارائه داکیومنت برای توسعه‌دهندگان و کاربران نهایی
